# Literature Seed List

This is the starting list for Chapter 4. It should be expanded and converted into APA style references before report submission.

## Dataset and Medical Image-Report Resources

- Demner-Fushman, D., Kohli, M. D., Rosenman, M. B., Shooshan, S. E., Rodriguez, L., Antani, S., Thoma, G. R., & McDonald, C. J. Preparing a collection of radiology examinations for distribution and retrieval. This is the key source for the OpenI / Indiana University chest X-ray collection.

## Retrieval-Augmented Generation

- Lewis, P. et al. Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks. This is the core RAG reference and should be used to explain parametric plus non-parametric memory.

## Biomedical Retrieval

- MedCPT: Contrastively pretrained transformers for zero-shot biomedical information retrieval. This is the planned dense retriever reference for the report-based and case-based RAG systems.

## Large Language Model Backbone

- Qwen2.5 technical report / model documentation. Use this to justify the selected instruction-tuned LLM.

## RAG Evaluation

- RAGAS and related RAG evaluation work for answer relevance, faithfulness, context precision, and context recall.
- Manual evidence-support checking should be included because automatic metrics alone are insufficient for medical claims.
